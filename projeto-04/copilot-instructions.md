# Copilot Instructions for Pixel Forge Studios

Context:
- Projeto fictício de portfólio de desenvolvedor de jogos indie.
- Tema Cyberpunk / Gamer com contraste forte, animações de CSS e layout moderno.
- Todas as páginas devem ser HTML5 sem JavaScript, usando apenas CSS3 para efeitos, animações e interações.
- O público é avaliador de portfólio e recrutadores de design front-end.

Estilo e voz:
- Use português claro e direto.
- Priorize acessibilidade, semântica e performance.
- Mantenha as classes e identações limpas.

Restrições:
- Não gerar JavaScript.
- Não usar bibliotecas externas além do Google Fonts.
- Todo o CSS deve estar em projeto-04/style.css.
- Use imagens placeholder de https://picsum.photos e https://i.pravatar.cc quando necessário.

Paleta de cores:
- Fundo principal: #0F0E17
- Destaque 1: #FF8906
- Destaque 2: #F25F4C
- Cinza escuro: #14121F
- Azul neon: #7C7FBA

Fonts:
- Títulos: Orbitron
- Texto corpo: Inter
- Código / tags técnicas: Fira Code
