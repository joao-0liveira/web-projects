# Prompts Reutilizáveis para Pixel Forge Studios

## Prompt 1 - Hero Animado
Gerar o HTML e CSS para a seção Hero com:
- título grande com efeito typing em CSS
- subtítulo de apoio
- botão pulse
- fundo com partículas CSS animadas
- layout responsivo para mobile e desktop
- cores: #0F0E17, #FF8906, #F25F4C
- fontes: Orbitron e Inter

## Prompt 2 - Sobre Split
Gerar HTML e CSS para a seção Sobre com:
- layout split 50/50
- texto à esquerda e imagem de perfil à direita
- moldura de gradiente giratório ao redor da foto
- texto em português curto explicando experiência fictícia
- sem JavaScript

## Prompt 3 - Skills em Cascata
Gerar HTML e CSS para a seção Skills com:
- quatro barras de progresso estilizadas
- animação de preenchimento automático com delays diferentes
- porcentagens visíveis e acessíveis
- cores neon e background escuro

## Prompt 4 - Flip Card 3D
Gerar HTML e CSS para a seção Projetos com:
- grade de cards 2x2 ou responsiva
- efeito flip 3D ao hover e foco por teclado
- frente com nome do jogo e imagem placeholder
- verso com descrição do projeto
- sem JavaScript

## Prompt 5 - Timeline Scroll Horizontal
Gerar HTML e CSS para a seção Timeline com:
- linha do tempo horizontal
- scroll-snap-type para cada marco
- pontos com animação pulsante
- texto de ano e evento
- responsivo para mobile

## Prompt 6 - Formulário de Contato Animado
Gerar HTML e CSS para a seção Contato com:
- campos de nome, email e mensagem
- estados de foco animados com bordas e sombra
- ícones sociais rotacionando ao hover
- botão de envio estilizado
- sem JavaScript
