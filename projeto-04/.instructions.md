# Instruções do projeto Pixel Forge Studios

Objetivo:
Criar um portfólio responsivo fictício para um desenvolvedor de jogos, demonstrando domínio de CSS avançado, animações e layouts não convencionais.

Seções obrigatórias:
1. Hero Animado: tela cheia, efeito typing no título, fundo com partículas CSS e botão pulse.
2. Sobre: seção split 50/50 com foto de perfil e moldura animada por gradiente.
3. Skills: barras de progresso com efeito de preenchimento automático em cascata.
4. Projetos: cards em grade com flip 3D ao hover, revelando descrição no verso.
5. Timeline: linha do tempo horizontal com scroll-snap e pontos pulsantes.
6. Contato: formulário animado com estados de foco e ícones de redes sociais rotativos no hover.

Requisitos técnicos:
- HTML5 sem JavaScript.
- CSS3 avançado: @keyframes, transform, perspective, scroll-snap, cubic-bezier.
- Layout responsivo e navegação fixa no topo.
- Priorizar contraste, legibilidade e acessibilidade.
- Use Google Fonts: Orbitron, Inter, Fira Code.

Dados de exemplo:
- Tagline: "Crafting immersive experiences with code and color."
- Skills: Game Design 95%, Unity 90%, CSS Avançado 92%, Animação 88%.
- Projetos: Moonlight Escape, Cyber Nexus, Neon Grid Racer, Void Guard.
- Timeline: 2019 a 2024 com marcos visuais.
- Imagens placeholder: Picsum Photos para capas de jogos e Pravatar para perfil.
