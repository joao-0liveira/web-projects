# Skill: Skills Bars

Descrição:
Gera a seção Skills com barras de progresso que se preenchem em cascata usando animações CSS e delays.

Entradas esperadas:
- Lista de habilidades e valores percentuais
- Cores de preenchimento: #FF8906, #F25F4C
- trackColor: #1C1A2B

Saída:
- HTML para skills-list com itens skill-item, skill-label e skill-bar.
- CSS com animação fill-bar e delays progressivos para cada barra.

Prompt de exemplo:
"Crie a seção Skills com quatro barras de progresso animadas em cascata para Game Design 95%, Unity 90%, CSS Avançado 92% e Animação 88%."
