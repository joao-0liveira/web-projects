# Skill: Hero Typing

Descrição:
Gera a seção Hero com um título em efeito typing, subtítulo e botão pulse. Inclui partículas de fundo feitas somente em CSS.

Entradas esperadas:
- title: texto principal do Hero
- subtitle: texto secundário
- buttonText: texto do botão
- primaryColor: #FF8906
- accentColor: #F25F4C
- backgroundColor: #0F0E17

Saída:
- HTML com a seção #hero e classes como hero-title, hero-subtitle, hero-button.
- CSS para animações typing, blink, pulse e partículas.

Prompt de exemplo:
"Crie a seção Hero HTML e CSS para Pixel Forge Studios com efeito typing no título 'Crafting immersive experiences with code and color.', botão pulse e partículas de fundo sem JavaScript."
