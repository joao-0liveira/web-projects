# Skill: Flip Card 3D

Descrição:
Gera a seção de projetos com cards que giram em 3D ao hover e foco. A face frontal mostra imagem e título, a traseira mostra a descrição do jogo.

Entradas esperadas:
- Lista de jogos com nome, descrição e imagem placeholder
- cardBackground: #14121F
- accentColor: #FF8906

Saída:
- HTML para container projects-grid e itens project-card.
- CSS para card-inner, card-front, card-back, transform 3D e transição suave.

Prompt de exemplo:
"Crie quatro cards 3D para a seção de projetos com Flip Card em CSS, usando imagens placeholder e foco acessível, cada card mostrando nome do jogo e descrição."
