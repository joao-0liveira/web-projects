# Skill: Contact Form

Descrição:
Gera a seção de contato com formulário de três campos, estados de foco animados e ícones sociais rotacionando no hover.

Entradas esperadas:
- Campos: nome, email, mensagem
- buttonColor: #FF8906
- focusBorder: #F25F4C
- Ícones sociais simples usando Unicode ou pseudo-elementos

Saída:
- HTML para contact-form com labels e placeholders.
- CSS para campos com transições, bordas, focos, botão e ícones sociais.

Prompt de exemplo:
"Crie um formulário de contato estilizado sem JavaScript, com campos de foco animados e ícones sociais rotativos."
