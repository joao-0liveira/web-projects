# Skill: Timeline Scroll

Descrição:
Gera a seção Timeline horizontal com scroll-snap e pontos animados para cada marco.

Entradas esperadas:
- Lista de eventos com ano e descrição
- lineColor: #7C7FBA
- pointColor: #FF8906

Saída:
- HTML para container timeline-wrapper, linha de tempo e itens timeline-card.
- CSS para layout horizontal, scroll-snap, animação pulsante dos pontos e responsividade.

Prompt de exemplo:
"Crie uma timeline horizontal com cinco marcos de 2019 a 2024, usando scroll-snap e pontos pulsantes em CSS."
